# NCT Vehicle Tracker

** Group Project **

A web application designed to help users manage vehicle information and keep track of important vehicle-related deadlines, including:

- NCT expiry dates
- Car insurance renewals
- Motor tax deadlines
- Vehicle maintenance and service history

## Key Features

- Reminders for upcoming NCT tests, insurance renewals and other deadlines.
- Visual alerts when important deadlines are overdue.
- Repeat reminders when a vehicle fails its NCT, helping users remember to arrange a retest.
- Vehicle maintenance tracking, including records such as brake changes.
- Vehicle issue reporting to help identify recurring problems.

## Technologies

- JavaScript
- Node.js
- Express.js
- MongoDB
- React
